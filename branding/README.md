# Bulkport brand

| Use | Colour |
|---|---|
| Brand (icon, listing, small accents in the app) | Deep teal `#0F766E` |
| Dark variant | `#134E4A` |
| Soft background | `#E6F4F2` |
| Accent (icon, listing only) | Amber `#F59E0B` |

Inside the app the look is Shopify's own (Polaris). Teal appears only on the Ask Bulkport box, the first-run
step numbers and the readiness score; green / red / amber / blue keep their meaning as status colours.

`icon.svg` is the source of the app icon; `icon-1200.png` is the 1200 x 1200 file for the Shopify App Store
listing and the Dev Dashboard.
