# Bulkport brand

| Use | Colour |
|---|---|
| Brand (icon, listing, small accents in the app) | Royal blue `#1D4ED8` |
| Dark variant | `#1E3A8A` |
| Soft background | `#E8EFFD` |
| Accent (icon, listing only) | Yellow `#FACC15` |

Inside the app the look is Shopify's own (Polaris). Blue appears only on the Ask Bulkport box, the first-run
step numbers and the readiness score; green / red / amber / blue keep their meaning as status colours.

`icon.svg` is the source of the app icon; `icon-1200.png` is the 1200 x 1200 file for the Shopify App Store
listing and the Dev Dashboard.
